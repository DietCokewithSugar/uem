## 3. 流水线【确认】

### 3.1 有效性判断

M1 有效性分析模型。输入 D1，输出 D2。

然后按这条声音已有的信息分支：

1. 没有所属产品信息：调取产品目录（既有数据），进入 M2。
2. 已有所属产品信息：再看有没有该产品的功能信息。
   - 没有：调取产品下功能目录（既有数据），进入 M3。
   - 有：再看该产品功能有没有旅程行为。
     - 没有：汇总声音定位数据，得到 D9。
     - 有：调取旅程结构，进入 M4。

【待定】这三支是只进入对应的一个模型，还是 M2 分完产品后还要继续做 M3、M4。已经走出 D5 的声音，要不要也汇总进 D9。M8 的输入写的是「D9 + 分类结果」，若 D9 只在「没有旅程行为」时产生，有旅程行为的声音如何进入典型问题提炼，文本没有写。

### 3.2 产品、功能、旅程行为分类

- M2 → D3
- M3 → D4
- M4 → D5

M4 使用调取到的旅程结构。旅程结构的范围见《灵犀旅程》：行为与触点。

### 3.3 ETS、情绪指数、严重性分值

这一段是并行分支。

1. M5 ETS 主维度分类 → D6
2. M6 情绪指数 → D7
3. M7 严重性分析 → D8

【待定】D6 是否只进入 D13，不参与 D12。文本把 D6 放在并行分支里，计算 D12 时没有列入 D6。

### 3.4 典型问题提炼

M8。输入是 D9 和分类结果。输出 D10：典型问题列表，按产品 / 功能 / 旅程分组。

### 3.5 优化点生成

M9。输入 D10。输出 D11：典型问题 + 应优化点列表。

### 3.6 声音严重等级

D12：有效声音严重等级。按加权公式计算。输入包含 D7 情绪指数、D8 严重性分值、D11 优化点信息。

【待定】加权公式的各项权重，以及「优化点信息」取 D11 的哪一列（条数、是否已有优化点，或其他）。

### 3.7 结果汇总

汇总全量分析结果，得到 D13：最终用户声音分析结果数据。D13 展示为声音看板中的可视化内容。
