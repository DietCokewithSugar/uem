# 用户体验管理平台 · 行外演示版（UEM Demo）

根据行内「用户体验管理平台（灵犀）」截图还原的**行外演示版本**，用于在行外环境展示平台框架、理解业务流程，并作为后续系统性重构（AI 结合、体验提升）的基线。

> 所有数据均为前端生成的虚构数据（`src/mock`），人员姓名随机生成，不连接任何行内系统。

## 运行

```bash
npm install
npm run dev      # 开发：http://localhost:5173
npm run build    # 打包到 dist/（相对路径，可直接静态托管）
```

## 技术栈

Vue 3 + Vite + Element Plus + ECharts + Vue Router（Hash 模式，路由与行内地址保持一致，如 `#/mainIndex`、`#/optimPending?type=&suggestStatus=2`）。

## 目录

```
src/
├─ config/menus.js        顶部导航、各板块左侧菜单、待办状态码
├─ layouts/
│  ├─ MainLayout.vue      安全提示条 + 红色页头 + 主导航 + 水印
│  └─ SectionLayout.vue   左侧分组菜单 + 面包屑 + 页面标题
├─ components/            查询表单、详情抽屉、图表、列表查询逻辑
├─ mock/index.js          演示数据（固定随机种子）
└─ views/
   ├─ home/               首页
   ├─ experience/         体验问题板块
   ├─ activity/           体验活动板块
   └─ common/Placeholder  尚无截图的页面占位
```

## 可交互的演示逻辑

- 待办列表勾选后「批量转处理 / 中止 / 删除 / 退回提交人」会真实改变记录状态，左侧待办数量与首页「待办工作」同步变化。
- 「新增」优化建议提交后进入「待分拣」。
- 数据管理中冻结的资讯不再出现在「方法培训 / 体验研究」；新增资讯按类型出现在对应卡片列表。
- 新增体验任务 / 体验活动后出现在对应列表；执行人为当前用户的任务会计入「待办工作 · 体验任务」。
- 编号可点击查看详情抽屉。
- 查询条件支持关键字、下拉、时间范围过滤，支持展开 / 收起。
