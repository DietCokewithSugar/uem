# 用户体验管理平台（灵犀）· 行外演示版

根据行内「用户体验管理平台（灵犀）」截图还原并改版的**行外演示版本**，用于演示平台的改版方向：

- 按岗位组合的首页卡片，每个人只看到与自己相关的待办、统计和数据范围；
- 重新梳理的导航，一级板块从「体验问题、体验资讯、体验员」等调整为按业务对象划分；
- 按已确认规则流转的优化建议：分行提交先审批，总行提交直达，按产品分类自动分配；
- 在提交、查重、分拣、答复环节由 AI 辅助，结果由人确认；
- 统一的「简洁专业」视觉风格。

> 所有数据均为前端生成的虚构数据（`src/mock`），人员姓名随机生成，不连接任何行内系统。AI 功能均为浏览器内的规则模拟，不调用模型。

## 运行

```bash
npm install
npm run dev        # 开发：http://localhost:5173
npm run build      # 打包到 dist/（相对路径，可直接静态托管）
npm test           # 单元测试：优化建议流转规则、权限与首页卡片
npm run test:e2e   # 路由巡检：用六个演示身份逐页打开全部页面，检查报错和空白页
```

推荐的演示路线：

1. **分行用户**：首页「提交优化建议」写一句话，例如「客户反映手机银行转账限额只能去网点调整」→ 进入提交页，「AI 整理」生成【现象】【建议】并识别产品、渠道等字段 →「填入表单」→ 提交。建议进入「待审批」。
2. **分行审批岗**：首页「我的待办」或「优化建议 · 待审批」中审批通过。系统按产品分类分配到对应研发部室的分拣岗，日志记为「系统 · 自动分配」。
3. **业务人员**：「待分拣」中参考 AI 推荐的答复人指派；「待答复」中可用「AI 答复草稿」，核对后提交答复。
4. **领导**：「待审核」中审核；首页查看优化建议概览、部门处理进展和声音异动。
5. 首页右上角「调整卡片」可显示、隐藏和排序卡片；「系统管理 · 首页维护 · 首页卡片配置」设置各岗位的默认卡片。

刷新页面会恢复初始演示数据；演示身份和首页卡片设置保存在本机浏览器中。

### 权限

- 所有人可用：首页的总行 / 分行资讯、方法培训、提交优化建议、我的提交、声音分析智能工具。
- 单独授权：全量优化建议导出、统计视图、管理报表、数据看板；全量声音看板需智能分析查看岗且产品领域为「全领域」。
- 其他模块沿用「人员维护」中的岗位；岗位上的数据范围决定看到哪些数据（如产品线、产品领域、部门）。
- 没有权限的菜单不显示，直接访问地址会提示并回到首页。功能与岗位的对应关系见 `src/config/access.js`。

### 优化建议流转

- 分行员工提交 →「待审批」（分行科技审核岗）→ 审批通过后自动分配。
- 总行员工提交、用户声音转入的建议直接自动分配，不需审批。
- 自动分配按产品分类（产品维护中的所属研发部室和产品线）进入对应分拣岗；没有分类的产品（演示数据中的「远程银行」「网点排队叫号」）进入用户体验部分拣岗；研发一体化产品转 e键通。
- 分拣、答复、审核由三个独立岗位完成，审核不通过退回答复人。详见 [docs/优化建议.md](docs/优化建议.md) 第 4 节。

### AI 辅助（规则模拟）

| 环节 | 做什么 | 位置 |
| --- | --- | --- |
| 提交 | 一句话整理成【现象】【建议】；识别产品、渠道、功能栏目、分类、影响程度、来源并给出置信度；脱敏手机号、证件号、银行卡号 | 首页「提交优化建议」、提交页「AI 整理」 |
| 查重 | 同义词归一后按语义查找相似建议，产品和功能栏目相同时加权 | 提交页 |
| 分拣 | 按同产品或同功能栏目的答复量、平均答复用时和当前待答复数推荐答复人 | 待分拣详情 |
| 答复 | 参考历史相似建议的答复生成草稿，列出参考的建议 | 待答复详情 |
| 技能 | 「帮你研」：用户研究方案与多源数据分析，分步确认的示例对话；「伴你想」：需求澄清梳理，构思中 | AI 工具 · 技能 |

AI 只给建议并写明依据，由人确认后才写入流程，操作日志中记为「AI 建议 · 人工确认」。

### 视觉

- 「简洁专业」风格：中性色打底，工行红只用于品牌、主操作、当前选中和风险；一套无衬线字体，固定字号阶梯；卡片不套卡片。
- 工行标识由上传的标识图矢量化（`src/assets/brand/`，原图在 `docs/brand/`）。
- 图表统一配色：一组数据一种颜色，不用渐变、彩虹色和表情图标，数量与比率不共用双纵轴。规范见 [DESIGN.md](DESIGN.md)。

## 可交互的演示逻辑

- **优化建议**：提交、审批、自动分配、分拣、答复、审核、跟进都会真实改变记录状态，左侧待办数量与首页「我的待办」同步变化。待审批列表可批量审批通过、退回提交人、中止或删除。
- **用户声音 → 优化建议**：声音看板「功能监测」中点击「转优化建议」，生成来源为「客户：用户声音智能分析」的建议，不经审批，按产品分类自动分配。
- **灵犀旅程**：维护中新增 →「待编辑旅程结构」→ 编辑器提交 →「待审核旅程」→ 审核通过发布到看板，或退回到「待修改旅程」。
- **体验质检**：上传截图、选择专家角色与用户画像，模拟生成单场景或 AB 方案对比报告。
- **体验官**：地区、所属机构级联筛选；异步导出生成任务，在「查看结果」中下载。
- **用户声音**：新增声音或点击「智能模型」时自动识别情绪与 ETS 维度；地图数据来自 MIT 协议的 china-geojson。
- **系统管理**：人员维护中修改岗位后，菜单和首页卡片立即变化；轮播图激活后首页横幅轮播；新增产品同步到全平台产品下拉，废弃产品自动移出；菜单维护修改一级板块名称、排序或冻结后导航立即变化。
- **体验问题维护**：开启「相似度」后，提交优化建议时会提示相似建议。
- **后台管理**：节假日 → 定时任务 → 邮件记录联动；接口权限决定日志管理是否可见（推测）。
- 统计视图按查询条件出数；编号可点击查看详情；查询条件支持关键字、下拉、时间范围过滤。
