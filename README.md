# 用户体验管理平台 · 行外演示版（UEM Demo）

根据行内「用户体验管理平台（灵犀）」截图还原的**行外演示版本**，用于在行外环境展示平台框架、理解业务流程，并作为后续系统性重构（AI 结合、体验提升）的基线。

> 所有数据均为前端生成的虚构数据（`src/mock`），人员姓名随机生成，不连接任何行内系统。行内统一认证号统一为 9 位纯数字（新增人员、体验员时校验）。

## 运行

```bash
npm install
npm run dev      # 开发：http://localhost:5173
npm run build    # 打包到 dist/（相对路径，可直接静态托管）
```

## 技术栈

Vue 3 + Vite + Element Plus + ECharts + Vue Router（Hash 模式，路由与行内地址保持一致，如 `#/mainIndex`、`#/optimPending?type=&suggestStatus=2`）。

## 目录

```
src/
├─ config/menus.js        顶部导航、各板块左侧菜单、待办状态码
├─ layouts/
│  ├─ MainLayout.vue      安全提示条 + 红色页头 + 主导航 + 水印
│  └─ SectionLayout.vue   左侧分组菜单 + 面包屑 + 页面标题
├─ components/            查询表单、详情抽屉、图表、列表查询逻辑
├─ mock/index.js          演示数据（固定随机种子）
└─ views/
   ├─ home/               首页
   ├─ experience/         体验问题板块
   ├─ activity/           体验活动板块
   └─ common/Placeholder  尚无截图的页面占位
```

## 可交互的演示逻辑

- 待办列表勾选后「批量转处理 / 中止 / 删除 / 退回提交人」会真实改变记录状态，左侧待办数量与首页「待办工作」同步变化。
- 「新增」优化建议提交后进入「待分拣」。
- 灵犀旅程完整流转：维护中新增 →「待编辑旅程结构」→ 编辑器提交 →「待审核旅程」→ 审核通过发布到看板，或退回到「待修改旅程」（附审核意见）。
- 体验质检：新增时上传截图、选择专家角色与用户画像，模拟「文件分析 → 维度评价 → 角色评估 → 汇总」生成报告。AB 对比分两次各上传一张修改前、修改后设计图，用演示数据生成对比报告（正式环境接入大模型）。
- 体验员：地区（省-市-区）、所属机构（分行-支行-网点）级联筛选；异步导出生成任务，「查看结果」中下载；点击统一认证号查看活动参与记录。
- 声音看板「功能监测」中点击「转优化建议」，典型问题会生成一条优化建议进入「体验问题 · 待分拣」，打通「用户声音 → 体验问题」闭环。
- 用户声音：新增声音或点击「智能模型」时自动识别情绪与 ETS 维度（演示为关键词规则，正式环境接入大模型）；地图数据来自 MIT 协议的 china-geojson。
- 系统管理：轮播图「激活」后首页横幅即轮播展示；新增产品同步到全平台产品下拉，废弃产品自动移出。
- 要客数据：在「人员维护」为当前用户勾选「要客标记」后，之后访问的每个页面都会按一/二/三级菜单记入「要客数据」。
- 菜单维护：修改一级菜单名称、排序或冻结后，顶部导航立即变化（系统管理、首页不可冻结）。
- 体验监测维护：新增或冻结重点渠道 / 精品产品后，「评价数据上传」中对应的上传项随之出现或隐藏。
- 体验问题维护：开启「相似度」后，新增优化建议时若与已有建议相似会提示「发现相似优化建议」，可返回修改或继续提交；关闭后不再提示。
- 数据管理中冻结的资讯不再出现在「方法培训 / 体验研究」；新增资讯按类型出现在对应卡片列表。
- 新增体验任务 / 体验活动后出现在对应列表；执行人为当前用户的任务会计入「待办工作 · 体验任务」。
- 字典维护：体验员「性别」、体验活动「体验渠道 / 体验方法 / 活动阶段」的选项来自字典，暂停某个字典值后对应下拉不再出现（推测）。
- 节假日 → 定时任务 → 邮件记录：「优化建议待办提醒邮件」每天 10 点执行，节假日中的非工作日跳过；在定时任务中「立刻执行」会给当前所有待办优化建议的处理人发送 dealSuggestion 邮件，邮件记录顶部即出现新的一批（推测）。
- 接口权限 → 日志管理：日志接口 GET /icbc/uem-server/log 的开启规则只放行「允许用户」或具备「权限」角色的人员，当前用户默认无权限，日志管理为空（与截图一致）；将其加入允许用户后即可查看、下载日志（推测）。
- 编号可点击查看详情抽屉。
- 查询条件支持关键字、下拉、时间范围过滤，支持展开 / 收起。
